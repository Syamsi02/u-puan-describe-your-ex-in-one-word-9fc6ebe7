One-word ex verdict picker: scores original candidates against the judge's criteria and writes the winner, TrialExpired, to entry.txt.

## Run it

```sh
python3 -P -s main.py
```

The program writes exactly one word to `entry.txt` inside the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`): `TrialExpired` — the free trial ended.
